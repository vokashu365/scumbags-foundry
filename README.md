# Scumbags / Подонки — система для Foundry VTT

Система для настольной ролевой игры «Подонки» (Scumbags): криминальный экшен-песочница, чёрная комедия и сатира в городе Порт-Мерси.
Работает в Foundry VTT 12 и 14. Интерфейс и компендиумы — на русском и английском.

## Установка

В Foundry: **Игровые системы → Установить систему**, внизу окна вставьте ссылку на манифест и нажмите «Установить»:

```
https://github.com/vokashu365/scumbags-foundry/releases/latest/download/system.json
```

## Что внутри

- Листы персонажа, NPC, транспорта (техпаспорт) и бизнеса; листы предметов с вкладками «Информация» и «Настройки».
- Броски по правилам игры: d10 + характеристика + навык, взрывающиеся кости, сложность стрельбы по дистанции, урон по выбранной цели с учётом брони.
- «Развитие» на листе персонажа: распределение 1000 XP по навыкам и очкам развития архетипов с автоматическим подсчётом.
- Компендиумы: готовые подонки, NPC, транспорт, оружие, броня, снаряжение, шпаргалка и карта Порт-Мерси (сцены и журнал).
